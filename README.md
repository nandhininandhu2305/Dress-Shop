# Thread & Tailor - Dress Shop (Frontend)

A responsive dress shop website for men, women and kids, with free 2-day delivery.

Built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Category filter (Men / Women / Kids)
- Add to cart, remove items, live total
- Free 2-day shipping section
- Contact form and mobile menu

## Run
Open `index.html` in a browser (internet needed for product images).
